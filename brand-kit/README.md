# Social Arrow brand kit

## Logos

Each folder has a **light** version (for light backgrounds) and a **dark** version (for dark backgrounds), as SVG and PNG.

| Folder | Use it for |
|---|---|
| `logo/horizontal` | Wide spaces: website, email signature, letterhead, deck title slides |
| `logo/wordmark` | The original "SOCIAL ARROW" lockup with the mark as the A |
| `logo/stacked` | Square spaces: posters, event standees, square posts |
| `logo/mark` | Small spaces: Instagram profile picture, app icon, watermark on reels |

**PNG** works everywhere (WhatsApp, Canva, PowerPoint). **SVG** stays sharp at any size; send it to designers and printers.

Don't stretch, recolour, rotate or add effects to the logo. Leave clear space around it at least the width of the flash circle on the mark.

## Colours

| Name | Hex | Use |
|---|---|---|
| Ink | `#15140F` | Text, dark backgrounds, logo square |
| Arrow red | `#E4472A` | Accent: arrow, highlights, key numbers |
| Deep red | `#B8341C` | Small red text on light backgrounds (more readable) |
| Paper | `#F5F2EC` | Main background |
| Sand | `#EAE5DA` | Secondary background |

## Fonts (free on Google Fonts)

- **Bricolage Grotesque**, ExtraBold: headings and the logo name
- **DM Sans**: body text
- **Noto Sans Devanagari / Bengali / Gujarati**: regional-language text
